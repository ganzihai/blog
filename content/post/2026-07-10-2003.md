![](https://wsrv.nl/?output=webp&url=https%3A%2F%2Fmmbiz.qpic.cn%2Fmmbiz_jpg%2FAok04jIpl1QIibmlXRIksnDIUdhtib0P9iawuF1icNJlzibldd1iaWpxTC95w5jInbXv0WPr3OQBswF9WZ1t7Tdcd67DmXYVD8tZS3A6d9r757Wpw%2F640%3Fwx_fmt%3Djpeg&from=appmsg)

PVE Tools Pro 是一个面向 Proxmox VE 9.x 的交互式 Bash 工具。 它不会替代 PVE 原生命令，而是把高频、易错、需要大量人工检查的运维动作收口为更清晰的菜单、更强的校验和更明确的高风险提示。

前段时间版本来回折腾、Go版迟迟出不来，很多人跟我一样：旧工具不敢停、新工具等不到，日常运维特别别扭。

现在尘埃落定：不再死磕Go重构，回归最稳、最好用、我们最熟悉的 Shell 版本长期维护。

下面与大家一起分享一下这款PVE虚拟机全能运维工具的使用指南！

一、运行 PVE Tools Pro 工具

1\. 一行命令快速运行：（任选一行即可，推荐第2条）

```js
# 1. cloudflare 短域名bash <(curl -sSL https://pve.u3u.icu/PVE-Tools.sh)# 2. 中国大陆网络bash <(curl -sSL https://ghfast.top/raw.githubusercontent.com/PVE-Tools/PVE-Tools-9/main/PVE-Tools.sh)# 3. 国际网络bash <(curl -sSL https://raw.githubusercontent.com/PVE-Tools/PVE-Tools-9/main/PVE-Tools.sh)
```

2\. 本地下载运行：

```js
# 下载脚本到本地，如果无法访问，可以替换上面的代理地址wget https://raw.githubusercontent.com/PVE-Tools/PVE-Tools-9/main/PVE-Tools.sh# 为脚本添加可执行权限 chmod +x PVE-Tools.sh# 运行 PVE-Tools sudo ./PVE-Tools.sh
```

重要提示：执行命令的时候，建议大家外部SSH环境下使用该功能！否则会导致PVE WebUi重启导致Shell断开连接修改失效！

二、PVE Tools Pro功能介绍

PVE Tools 的所有功能如下图所示，可以根据自己的需求选择对应序号：

```js
  1  . 日常优化与通知 ( 弹窗 / 温度 / 电源 / 邮件 )  2  . 软件源与系统升级 ( 换源 / 更新 / PVE升级 )  3  . 启动与内核管理 ( 内核 / GRUB )  4  . 硬件直通与显卡 ( IOMMU / GPU / RDM / NVMe )  5  . 虚拟机运维与导入 ( 镜像 / 备份 / 恢复 / Cloud-Init )  6  . 宿主机网络与防火墙 ( 网桥 / VLAN / Bond / 规则 )  7  . 存储与磁盘维护 ( 路径 / 挂载 / 清理 / Ceph )  8  . 诊断工具与项目信息 ( 系统信息 / 救砖 / 脚本管理 )  9  . 安全中心 ( 风险检查 / SSH加固 )  10 . 第三方工具 ( CoolerControl / Modules / 社区脚本 )
```

![](https://wsrv.nl/?output=webp&url=https%3A%2F%2Fmmbiz.qpic.cn%2Fmmbiz_png%2FAok04jIpl1SfEpFBENH0jBxzutCDgIJBBJJvDJ8y0XVcOdbH6oP0smm1XwjdOGOG4NGy2oGsHQ7hicsTLDbVhcqUenRl13rUZl8KQQic6mVGQ%2F640%3Fwx_fmt%3Dpng&from=appmsg)

1\. 如果我们需要 “换源+删弹出+更新”，可以在上面的窗口输入 1 ，然后进入【系统优化】界面后，输入 2跟着提示一步步操作即可。

![](https://wsrv.nl/?output=webp&url=https%3A%2F%2Fmmbiz.qpic.cn%2Fsz_mmbiz_png%2FAok04jIpl1Rk2fEuAloUM7yjziassFicorojoECZIpkZg41MeFz3DlUYYKVyPCxueTDw4BuRUdTiayh5SJ0ibM9dDXCThZyNImjGQvjnQZuTjIs%2F640%3Fwx_fmt%3Dpng&from=appmsg)

2\. 如果我们需要处理这几天爆出的 “潜伏16年的 KVM 逃逸漏洞 Januscape (CVE-2026-53359)”，可以在主界面输入 9 ，进入【安全中心】，然后输入 3 进入【CVE 漏洞修补中心】。

![](https://wsrv.nl/?output=webp&url=https%3A%2F%2Fmmbiz.qpic.cn%2Fsz_mmbiz_png%2FAok04jIpl1TT39Qfc4yhzXia2hsoeQuM1JCicyGqHCRME1th9Nol1icRzMxmrw6BgErg0niaDwwicNAzL7uYX5Pu3cM99Uec6WUTaN35dRbPAsQw%2F640%3Fwx_fmt%3Dpng&from=appmsg)

3\. 可以根据自己的服务器环境，选择修补选项，1,2,3为单独修补，8为一键批量修补所有漏洞（注意：以上选项只是缓解措施），要想彻底修复，还是建议执行 9 ，通过升级内核来彻底修复所有 LPE 漏洞。

![](https://wsrv.nl/?output=webp&url=https%3A%2F%2Fmmbiz.qpic.cn%2Fsz_mmbiz_png%2FAok04jIpl1QMVziajt855sVKJJKYh7FSC90cyicrsIZpRYIrgyjxR6q0u82S8ZNh22HKazdKCh4kptRSR9Hfo8NmYHtTPzdITvzBPuECBYqU0%2F640%3Fwx_fmt%3Dpng&from=appmsg)

4\. 注意：执行修复后会有以下影响：

 • 关闭嵌套虚拟化：VM 内无法运行嵌套 VM (L2)

 • 关闭 IPsec ESP：影响 VPN/隧道功能

 • 所有措施重启后生效

 • 升级内核后可逐一恢复各项功能

![](https://wsrv.nl/?output=webp&url=https%3A%2F%2Fmmbiz.qpic.cn%2Fsz_mmbiz_png%2FAok04jIpl1QJJ7bRxQOyKKc4ZzW6SeZ6iblJT7SnicvJsBicmicTIZpvcx5T7280E21L45TlBUeqAQF5Zo2oNhMO2UicdGibkibGLwA6dv67yZxlibE%2F640%3Fwx_fmt%3Dpng&from=appmsg)

5\. 然后我们输入 BATCH-FIX 然后回车，即可触发批量修复程序，自动完成漏洞修复工作，完成后，输入 yes重启系统即可。

![](https://wsrv.nl/?output=webp&url=https%3A%2F%2Fmmbiz.qpic.cn%2Fsz_mmbiz_png%2FAok04jIpl1SIEDTibLz5wRdYU29HLJUk0ZzKH9LAX0ceT4k7mNicpic00iaD8W1HcIcibyb2SZjv6Leduibu5acDIEN1Lr6qA5B6ibmRH3jSicRhPKk%2F640%3Fwx_fmt%3Dpng&from=appmsg)

6\. 其他功能大家按需使用即可，这里就不一一列举了！

PVE Tools 本质上就是帮我们把繁琐、易错、难查的命令做成可视化菜单，降低折腾门槛，而不是搞花里胡哨的技术噱头。
