**📱 五、手机端傻瓜式使用教程（零基础看懂）**

搭建完成后，全程手机操作，超简单！

**1. 登录 SignTools 后台**
打开手机 Safari 浏览器，输入：`电脑IP:3000`。输入你设置的管理员密码，成功登录后台界面。

**2. 导入签名证书（首次搭建必做）**
*   左侧点击「Certificates」上传你的 P12 证书，填写证书密码保存。
*   左侧点击「Profiles」上传你的 mobileprovision 描述文件。
*   点击「Signing Configs」新建签名配置，绑定刚上传的证书 + 描述文件，保存即可。

**3. 上传需要安装的 IPA**
点击页面「Upload App」，从手机文件中选择你要安装的 APP 安装包，等待上传完成。

**4. 一键签名应用**
上传完成后点击右侧「Sign」，选中刚才创建的签名配置，点击开始签名。等待 1-3 分钟，系统自动完成签名（取决于安装包大小）。

**5. 安装 + 信任应用（关键！防闪退）**
*   签名成功点击「Install」，无线安装应用到手机桌面。
*   **iOS 16 及以上**：设置 → 隐私与安全 → 开启开发者模式，重启手机。
*   **iOS 15 及以下**：设置 → 通用 → VPN 与设备管理 → 信任开发者证书。

**📄 六、小白专属：证书 & 设备 UDID 获取方法**

**1. 设备 UDID 获取**
手机连接 Mac，打开 Xcode → 窗口 → 设备与模拟器。选中你的手机，右键直接复制 【 设备标识符（UDID）】 即可。

**2. 免费证书获取**
*   浏览器登录【Apple 开发者官网】。
*   进入证书管理页面，创建「iOS 开发证书」。
*   配合电脑钥匙串生成 CSR 文件，导出 P12 证书。
*   创建 APPID、绑定设备 UDID，最后下载描述文件。

**❗ 七、高频报错问题｜一键排查修复**

| 常见问题 | 核心原因 | 解决办法 |
| :--- | :--- | :--- |
| 签名任务失败 | 证书、描述文件不匹配 | 重新制作对应 BundleID 的证书和配置文件 |
| 安装后闪退 | 未信任证书 / 签名过期 | 重新信任证书，免费账号 7 天重签一次 |
| 超出应用限制 | 免费账号上限 3 个 APP | 更换备用 Apple ID 签名 |
| 网页无法打开 | 电脑手机不在同一网络 | 统一 WiFi，关闭电脑防火墙 |
