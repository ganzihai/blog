每个月你的云服务器账单是多少？

轻量应用服务器，最便宜的配置也要几十块一个月。学生党、独立开发者、副业程序员，为了省这点钱，要么忍着用本地环境，要么凑合用免费的低配机器——内存不够、带宽拉胯、换台电脑就得重新配环境。

但有一个东西，大多数人注册了 GitHub 账号却从来没打开过。

它叫 **GitHub Codespaces**。微软旗下，合法免费，每个月送你 **120 小时**的云端开发环境。配置是 2 核 CPU + 4GB 内存，网络走微软 Azure 骨干，速度比你家宽带稳得多。

---

**01 这东西到底是什么？**

**GitHub Codespaces** 是微软在 2021 年正式推出的云端 IDE 服务。简单说，就是把一台 Linux 服务器和 VS Code 打包在一起，放到浏览器里给你用。

你打开任意一个 GitHub 仓库，点一下 Code 按钮，选 Codespaces，30 秒之内一个完整的开发环境就启动了。

不需要装 Node、不需要配 Python 版本、不需要折腾 Docker。环境跟着仓库走，换台电脑打开浏览器，接着干。

对比 Gitpod、CodeSandbox 这类同类产品，Codespaces 的优势在于：它和 GitHub 生态是原生打通的，私有仓库、Actions、Secrets 全部无缝联动。

---

**02 免费额度够不够用？**

很多人听到 "免费" 就觉得是噱头，先看数字。

GitHub 免费账户每个月的额度：

* **120 小时**使用时长（2 核机型）
* **15GB** 存储空间
* 超出后按量计费，但手动设置支出上限为 0 就不会产生任何费用

120 小时是什么概念？每天用 4 小时，可以用整整一个月。而且 Codespaces 是按 "活跃时间" 计费，不是按开机时间——你最小化窗口去摸鱼，它不扣你的额度。

**反常识的地方在这里：** 很多人以为免费版只能用低配机器，实际上免费额度对应的是 2 核 4GB 的标准机型，这个配置跑大多数 Web 项目、跑 Python 数据分析、跑 Node 服务，完全够用。

---

**03 三个真实使用场景**

**场景一：临时跑一个开源项目**

你在 GitHub 上看到一个有意思的项目，想本地跑起来看看效果。按照传统流程：clone 仓库、装依赖、解决环境冲突、等待……没有半小时搞不定。

用 Codespaces：打开仓库页面，按下句号键（`.`），直接进入 Web 版 VS Code。如果项目有 `devcontainer.json` 配置，点击 Codespaces 启动，依赖自动安装，端口自动转发，5 分钟内看到运行结果。

**场景二：没有电脑的时候改 Bug**

出差、在外面，手边只有一台 iPad 或者别人的电脑。线上有个紧急 Bug 要修。

Codespaces 直接在浏览器里开，改完提交，全程不需要在别人电脑上装任何东西，也不会留下任何代码痕迹。

**场景三：学习新技术栈**

想学 Rust、想试试 Deno、想跑一个 Go 项目，但不想污染本地环境。

开一个 Codespaces，装完玩完，直接删掉。本地干干净净，什么都没留下。

---

**04 怎么开始用？**

操作路径极简，三步到位：

**第一步**，登录 GitHub，进入任意仓库（或者新建一个空仓库）。

**第二步**，点击绿色的 Code 按钮，切换到 Codespaces 标签，点击 "Create codespace on main"。

**第三步**，等待 30 秒左右，一个完整的 VS Code 环境在浏览器里打开。

> 建议第一次使用时，在 GitHub 设置里找到 Codespaces 选项，把 "Spending limit" 设置为 0 美元，彻底杜绝超额扣费的可能。

如果你习惯用本地 VS Code，也可以安装 **GitHub Codespaces 插件**，把云端环境直接连接到本地客户端，体验和本地开发完全一致，只是计算资源跑在微软的服务器上。

---

**05 进阶：用 devcontainer 定制你的环境**

Codespaces 真正强大的地方，是支持 **Dev Container** 规范。

在仓库根目录放一个 `.devcontainer/devcontainer.json` 文件，里面声明你需要的运行时、插件、环境变量，每次启动 Codespaces 都会自动还原成这个状态。

团队协作场景下，这个功能价值极高。新人加入项目，不需要对着一份十几步的环境搭建文档操作，打开 Codespaces，环境自动就绪，当天就能提交代码。

这是 Codespaces 和 Gitpod 共同推动的方向，微软已经把 Dev Container 规范开源，JetBrains、Podman 等工具也在跟进支持。

---

**06 一句话总结**

**GitHub Codespaces** 是目前免费额度最厚道、和 GitHub 生态结合最深的云端开发环境。每月 120 小时，够大多数轻度开发者零成本使用全年。

现在打开你的 GitHub，找一个最近在看的开源项目，按下句号键，感受一下什么叫 "打开浏览器就开始写代码"。
