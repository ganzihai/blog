出门在外想进服务器救急，手边没带电脑，借别人的电脑又没装 SSH 终端？

**EdgeSSH**（aozorae 开源，Apache-2.0）把一整套运维工作台搬进了浏览器：主机管理、在线终端、文件传输、系统监控全收在一个界面里，而且是部署在你自己的 Cloudflare 账号上。

29 天前刚创建，269 个 star。

适合手里有 VPS 或云服务器、经常需要在不同设备间连终端的人。

#### 01 核心玩法

**不用再专门买一台 VPS 当 WebSSH 中转机。**

以前搭 WebSSH，通常得自己掏钱养一台中转服务器跑后端。

EdgeSSH 完全依托 Cloudflare 的无服务器架构：网页只管前端交互，后端逻辑交给 Worker，每个 SSH 会话由独立的 Durable Object 容器承载，直接通过 Cloudflare 的 TCP 管道连回你的服务器。

数据、配置和网关都在你自己的 Cloudflare 账户里。

![](https://wsrv.nl/?output=webp&url=https%3A%2F%2Fmmbiz.qpic.cn%2Fsz_mmbiz_png%2FRCgtXod1WxNM7y7ckDxRLhibxwdYOtwjwlVMyyXCe1KKnwEI2HHia74B6PZkpmSiamzkic8Fhvyd01HCn9djAYh4nSZ2AzsCaAR4y5AjKVuBSibw%2F640%3Fwx_fmt%3Dpng&from=appmsg)

用起来就像一个完整的轻量运维客户端：

* **打开浏览器就是全功能终端**：基于 xterm.js，支持密码、SSH 私钥与多因子交互认证，窗口大小随网页自适应。第一次连接某台主机时，它会主动弹窗展示该机器的 SHA-256 密钥指纹，确认无误后才会发送登录凭据。

![](https://wsrv.nl/?output=webp&url=https%3A%2F%2Fmmbiz.qpic.cn%2Fmmbiz_png%2FRCgtXod1WxNJkmMYsWPFTw7mljkZep8DfwTzD5VtVYRj27WQMp2NKKL4IVfFFGhBbyATwiaQcFSUb6CLW1lztQ61pyMkq7giaoPP57ENWcsfU%2F640%3Fwx_fmt%3Dpng&from=appmsg)

* **改配置文件不用另开软件**：自带基于 SFTP 的文件管理器，目录浏览、上传下载、重命名、在线改文件一气呵成。它和终端共用同一个会话，两者之间来回切换完全不需要重新连线。

![](https://wsrv.nl/?output=webp&url=https%3A%2F%2Fmmbiz.qpic.cn%2Fmmbiz_png%2FRCgtXod1WxP9aVNMibE5KAzN5EicXblt0PcaHhypvp9vjico1vt9R7Q15FFA9tTOTKK7sMDqKp8OHzBfjicILPgOWRxncSHj97ha8EG2JdAEibzA%2F640%3Fwx_fmt%3Dpng&from=appmsg)

* **服务器状态一眼看清**：直接抓取服务器状态，在界面里实时显示 CPU、负载、内存、Swap 占用和进程列表——**机器上完全不用额外装探针 Agent**。甚至还带 HTTP 端口转发，服务器上那些只监听本地 `127.0.0.1:3000` 的内部 Web 面板，在 EdgeSSH 里点一下就能临时打开预览。

![](https://wsrv.nl/?output=webp&url=https%3A%2F%2Fmmbiz.qpic.cn%2Fmmbiz_png%2FRCgtXod1WxPia1mpoPfqO9CW8l6IiajR3waMjQf0BWePEadhNWiaVxcjlCjxibhuvo6EjLB5ibN5BBGvVoYPXxWzNQ3OOm2ibiaMFqyk9MHgBXDDUM%2F640%3Fwx_fmt%3Dpng&from=appmsg)

主机密码和私钥在存入 Cloudflare D1 数据库前，都会经过 AES-256-GCM 本地高强度加密。

#### 02 怎么用

直接部署到自己的 Cloudflare 个人账户。最快的方式是 Fork 官方仓库，在 GitHub 申请一个免费的 OAuth App 作为唯一登录入口，借助仓库自带的 GitHub Actions 就能全自动打包部署到 Cloudflare Workers。

部署完成后打开专属网址，添加服务器 IP 和密钥即可直接连入。
