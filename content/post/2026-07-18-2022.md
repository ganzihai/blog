**签到工具配置**

1. 将抓包工具中的参数整理为以下格式：

```
user=张三; kps=abcdefg; sign=hijklmn; vcode=111111111;
```

2. 回到你上面 Fork 的仓库，进入 **Settings -> Secrets and variables -> Actions**。

![](https://wsrv.nl/?output=webp&url=https%3A%2F%2Fmmbiz.qpic.cn%2Fmmbiz_png%2F6OnfckiaI1sDc5LeH8pphYWEguialiasVSR75tpVFu7ibygyqeDkNpoaLDgFNFQgPpQYvhibeccUOM8d5XV6ccKcFjzDAe9XmRNELD32tZWH96vs%2F640%3Fwx_fmt%3Dpng&from=appmsg)

3. 点击 **Repository secrets** 分区下的 **New repository secret** 按钮，创建名为 `COOKIE_QUARK` 的 Secret。

![](https://wsrv.nl/?output=webp&url=https%3A%2F%2Fmmbiz.qpic.cn%2Fmmbiz_png%2F6OnfckiaI1sC37egrqKCJsrEGgPbcqubUXYtaXGxwoCJu8MPAPIU2ibz0iaUPLdWBcWicibibsSQtoydnKIzSDDlVnlghYzq6WBFqcCg5IbkCuoqs%2F640%3Fwx_fmt%3Dpng&from=appmsg)

4. 进入 **Actions** 选项卡。如果看到黄色的提示条 "Workflows aren't right ....... enable them"，点击 **"I understand my workflows, go ahead and enable them"** 按钮启用 Actions。

![](https://wsrv.nl/?output=webp&url=https%3A%2F%2Fmmbiz.qpic.cn%2Fmmbiz_png%2F6OnfckiaI1sAwqqyn9fmp958sahFXkNnNUNBTDv43KlUpcdprMtbnGVSs81jSLibQL8dz7vLKIaTpzFvYIFj12pSfQwAUAqRhBuU7IVILyicTw%2F640%3Fwx_fmt%3Dpng&from=appmsg)

5. 进入仓库的 **Settings -> Actions -> General** 页面，在 "Workflow permissions" 部分，选择 "Read and write permissions"，点击 "Save" 保存。

![](https://wsrv.nl/?output=webp&url=https%3A%2F%2Fmmbiz.qpic.cn%2Fsz_mmbiz_png%2F6OnfckiaI1sA1C0n1T1WO85Gmibf8DtPMhhooNBp6cJ4ibnoH17uVuYp4e3VZnFMSdb94A8SJHnb3ebX4ACQqXsJ6ZwYuqNyKiboNvsvW2uBuhs%2F640%3Fwx_fmt%3Dpng&from=appmsg)

![](https://wsrv.nl/?output=webp&url=https%3A%2F%2Fmmbiz.qpic.cn%2Fsz_mmbiz_png%2F6OnfckiaI1sAd9t65NkbsiaIribhLB6Gd5u2MCUI1N6l4Wq27Rt0BrgLbpXHZQgKGeetUy5ia2W0G1UABYovybJ5jyvv0Eial0Ks8zDaibmDfmuL4%2F640%3Fwx_fmt%3Dpng&from=appmsg)

6. 回到 Actions 选项卡，你会看到名为 `Quark签到,点击启用` 的工作流。

![](https://wsrv.nl/?output=webp&url=https%3A%2F%2Fmmbiz.qpic.cn%2Fsz_mmbiz_png%2F6OnfckiaI1sCPKEmIWpl7gpZW0rfBK75BoNaiawygBQqHBXIGwjWEib7ib9hyEQCN4mDG5blKUoz0LIXdlo41LrpsdooNfJptWtrxVa70UTOIHA%2F640%3Fwx_fmt%3Dpng&from=appmsg)
